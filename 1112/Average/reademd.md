# MASM 5개 숫자 평균 구하기 프로그램

Visual Studio 환경에서 Microsoft Macro Assembler(MASM)를 사용하여 5개의 정수를 입력받고, 그 숫자들의 평균(정수 나눗셈 기준)을 계산하여 출력하는 x86 어셈블리 프로젝트입니다.

---

## 🛠️ 개발 환경 및 요구 사항
* **IDE**: Visual Studio 2022 (또는 호환 버전)
* **어셈블러**: MASM (`ml.exe`)
* **아키텍처**: x86 (32비트 콘솔 응용 프로그램)

---

## ⚙️ 프로젝트 설정 방법

1. **프로젝트 생성**
   * Visual Studio에서 **[C++]** -> **[빈 프로젝트 (Empty Project)]**를 생성합니다.
2. **MASM 빌드 사용자 지정 활성화**
   * 솔루션 탐색기에서 프로젝트 우클릭 -> **[빌드 종속성] -> [빌드 사용자 지정(Build Customizations...)]**에서 **`masm`**에 체크합니다.
3. **소스 파일 추가 및 속성 변경**
   * `main.asm` 파일을 추가합니다.
   * 파일 우클릭 -> **[속성]** -> **[일반]** -> **[항목 형식(Item Type)]**을 **[Microsoft Macro Assembler]**로 변경합니다.
4. **인코딩 설정 (한글 깨짐 방지)**
   * 소스 파일 저장 시 인코딩을 **`한국어(Koo-Korean) - 코드 페이지 949`**(또는 `UTF-8`)로 설정하여 한글이 깨지지 않도록 합니다.

---

## 💻 소스 코드 개요 (`main.asm`)
* C 런타임 라이브러리(`printf`, `scanf`)를 연동하여 표준 입출력을 수행합니다.
* 반복문(`ecx = 5`)을 통해 5개의 정수를 순차적으로 입력받고 누적 합(`sum`)을 계산합니다.
* `idiv` 명령어를 사용하여 총합을 5로 나눈 뒤 정수 평균값을 콘솔에 출력합니다.
